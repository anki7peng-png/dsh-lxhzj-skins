# 「小黑·森林」素材来源与授权

## 成品构成

本目录的 `background.webp` 与 `working.webp`、`waiting.webp`、`idle.webp`、`unknown.webp` 为**完全自用**的 DSH 皮肤素材，按项目所有者 2026-11-12 的确认制作：

- **背景**：默认版取自 `影视提帧素材/第41集_开始学习吧小黑同学/场景与细节/第41集_00-01-57.042_林下树影与光斑.png`（源视频 PTS `00:01:57.042`，3840×2160）。处理为 16:10 裁切、去除右上角源内哔哩哔哩标识、压暗调色、加暗角与颗粒；没有加入其他角色，未改动原帧文件。`background-win.webp` 是同一母版的 Windows 备用提亮版；0.1.9 起改用桌面壳 frame 透明化修复，该文件暂不启用。`background-animated.webp` 取自同一集 1:58–2:00 的完整森林镜头，循环 38 帧（1600×1000），做过偏绿调色；原视频文件不入库。
- **角色四态**：角色本体直接取自 `角色卡/罗小黑/原形_官方设定图.png`，用 GrabCut 从原图裁出小黑，保留原始像素、眼睛、耳朵与尾巴；再叠加状态道具/雾化：`working` 加符文笏板、`waiting` 加琥珀问询符、`idle` 加叶片“z”、`unknown` 加下半身雾化。没有重绘小黑本体。
- **眼睛跟随版**：`working-gaze.webp`、`waiting-gaze.webp`、`idle-gaze.webp` 是在上一步基础上把固定瞳孔填成眼白（保留原眼形/轮廓），由界面叠加两枚可移动的 DOM 瞳孔；`unknown` 不使用跟随版。
- **状态差异**：四态共用官方原形坐姿；状态主要靠道具、色环、雾化与界面标题区分。若需要不同官方姿势，可后续继续从影视帧中挑选并裁切。
