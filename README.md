# 罗小黑系列 DSH 皮肤

一个 DSH 皮肤插件，提供六套《罗小黑战记》主题，并支持在 DSH 内切换主题和管理本机通知。

## 功能

- 六套主题入口；目前「小黑·森林」可用，其余显示「素材待制作」。
- 主题切换立即生效，包含背景、配色和角色状态图。
- 会话状态联动：执行、等待、空闲、失联时显示对应的小黑状态。
- 欢迎页展示动态小黑；页面闲置 10 秒后，输入框右侧小黑播放尾巴动画。
- 支持插件内检查更新。
- 本机通知默认关闭，可在设置中开启本轮结束、审批请求和问题提醒。
- 尊重 `prefers-reduced-motion`，关闭动画。
- 支持 Windows 客户端背景显示。

## 安装

在 DSH「插件 → 添加插件」中输入仓库地址：

```text
https://github.com/anki7peng-png/dsh-lxhzj-skins
```

或：

```text
github:anki7peng-png/dsh-lxhzj-skins
```

安装后重启 DSH。

Windows 安装说明见 [docs/Windows安装.md](docs/Windows安装.md)。

## 使用

- 在「设置 → 罗小黑皮肤与管理」选择主题。
- 通知在同一个设置页开启，并按系统提示授予通知权限。
- 插件详情页也保留主题与通知设置。
- 在插件详情页可检查更新；直连失败时会尝试第三方加速源，下载更新仍需访问 GitHub。

## 代码说明

- `lib/index.js`：读取主题资源，提供按皮肤隔离的资源路由，并注册本机通知桥接。
- `lib/client.js`：注册主题选择、设置页和通知开关；应用背景、配色、角色状态图、欢迎页 Logo 与闲置动画。
- `lib/updates.js`：检查 GitHub `main` 的最新提交；更新安装由 DSH 插件管理器执行。
- `lib/notification-mac.js`：提供 macOS 本地通知的受限 HTTP 桥接。
- `macos/`：可选的本地通知助手源码、构建脚本和小嘿咻图标。
- `test/`：资源路由、客户端渲染、通知和更新逻辑测试。
