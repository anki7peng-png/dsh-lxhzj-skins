### 状态实测细节

- 执行态：`working` 图悬浮在输入栏右侧，绝对定位，不占 composer 高度；尺寸 118px；标题「小黑 · 巡林」。
- 等待态：`ask_user_question` 触发 `pendingInteraction`，composer 被提问面板替换；完整状态图不可见是 DSH 的正常布局行为，因此新增 `conversation.session.header.actions` 槽位的 34px 圆形头像，裁切到脸部，琥珀描边。运行时测得 `data-luoxiaohei-state="waiting"`、头像尺寸 34×34。
- 空闲态：停止生成后 `running === false`，显示官方坐姿 + 叶片 z 与「小黑 · 小憩」。
- 未知态：无 session status 时回退到 `unknown`，不会误报成功；该态使用静态图，不做眼睛跟随。

## 4. 未验证与限制

- **macOS 桌面端**：本插件装在隔离 `skinlab` Web profile；当前桌面 profile（0.2.2-rc.2）未安装，未在桌面窗口内验收。桌面端与 Web 端共用同一客户端插件接口，但仍需一次真实安装/重启验收。
- **Windows 桌面端**：无环境，未测。
- **GitHub 安装**：已在 macOS 隔离 Web 用 public 仓库验证（0.1.4）；Windows 桌面端安装与运行未测。
- **高 DPI / 多显示器**：未做 2x、超宽屏、竖屏的系统性检查。
- **视觉回归**：目前是人工截图验收，没有像素级 visual regression。
- **等待态完整角色图**：DSH 的提问/审批面板会接管 composer，完整状态图随 dock 卸载；当前用标题旁小头像承接。若未来 DSH 提供常驻 overlay 槽位，可把完整等待图移过去。
- **提示范围**：森林耳语跟随当前打开的会话，跨会话的后台任务只靠 DSH 侧栏原生状态点；目前没有声音提示或系统级通知。
- **Windows 背景**：Windows 桌面壳会压暗壁纸，因此新增只在 Windows 生效的 `background-win.webp` 和更轻的遮罩；这是模拟验收，实际 Windows 观感仍需实机确认。
- **Windows 原生菜单**：左下角“设置/意见反馈/登录”菜单属于桌面壳原生 UI，不在 Web 皮肤的 DOM/token 覆盖范围；未修改。
- **素材边界**：成品直接使用官方原形设定图与第 41 集影视帧，按项目所有者确认作完全自用；仓库当前为 public，仅作跨设备试用与备份，不构成对第三方的商用/再分发授权，不冒充官方素材。四态共用同一官方坐姿，状态靠道具/雾化区分。

## 6. 复现命令

```bash
# 单元测试
cd dsh-skin-xiaohei
npm test

# 隔离 Web profile（示例；token 由 dsh 打印）
# 1) 在 ~/.dsh/profiles/skinlab/package.json 中加入：
#    "dsh-luoxiaohei-skins": "file:/绝对路径/dsh-skin-xiaohei"
#    并把 "dsh-luoxiaohei-skins" 加入 dsh.profile.bundles
# 2) pnpm install（使用 DSH 自带 pnpm）
# 3) 启动
dsh --profile skinlab --host 127.0.0.1 --port 0 --no-open
```

插件选择写在 DSH 配置中；测试结束后可在插件页切回「DSH 默认界面」。
