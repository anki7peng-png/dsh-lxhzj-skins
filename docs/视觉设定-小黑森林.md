# 「小黑·森林」视觉设定

## 1. 方向

一句话：**把动画里的森林直接搬进 DSH**——背景取自第 41 集 `00:01:57.042` 的林下树影帧，保留原片的手绘树冠、巨木、山野和蝉；小黑的角色图直接裁自官方原形设定图，保留奶油色眼白、黑瞳、绿耳和长尾。四态只叠加状态道具/雾化，不重画角色本体。

按项目所有者确认，本皮肤为**完全自用**；仓库当前为 public，仅作跨设备试用与备份，不构成对第三方的商用/再分发授权。

## 2. 画面与构图

- **画布**：3200×2000（16:10），由 3840×2160 影视帧裁切、压暗、去源内水印后得到。
- **右侧**：巨木主干与树皮占据右 1/3，形成稳定的暗部框架。
- **上方**：大片手绘树冠从左上压下来，横枝斜穿画面，是原帧最有辨识度的部分。
- **中部**：淡青山脊、屋舍和田野，给界面留出呼吸区；遮罩后中心偏暗，承托对话与输入框。
- **细节**：树干上的蝉保留原帧的趣味点，不做擦除。
- **角色**：不在背景中重复出现；小黑以悬浮状态图出现在输入栏右侧、状态行右端，不占输入区高度，避免和主题卡、消息区抢焦点。

界面另加左侧/底部渐暗、整体暗角和极轻颗粒；不再叠加大面积紫藤/月轮光效，以免破坏原帧的手绘质感。Windows 桌面壳的 `.mP3x-q_frame` 会以 86% 深色填充盖住壁纸；Windows 下将该 frame 透明化，直接显示基础背景。`background-win.webp` 仅保留为备用。蝉动画使用去蝉静态底图 `background-no-cicada.webp` + 透明 `cicada-animated.webp` 覆盖层，树颜色不变。

## 3. 配色

背景本身提供主色：高饱和树冠绿、黄绿树干、淡青山脊与灰白天空。UI 在此基础上取深松墨绿、苔玉和暖白：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 墨松 | `#04100b` / `#07120d` | 页面底色、最深遮罩 |
| 深林 | `#0d2b1e` / `#173e2b` | 面板、玻璃层 |
| 苔玉 | `#93e7b3` / `#6fdc9e` | 主强调、按钮、状态点 |
| 月金 | `#ffd99a` / `#e8c27c` | 等待态道具、暖色点缀 |
| 雾白 | `#f0f7ef` / `#c3d6c6` | 主文字、次级文字 |
| 原片黑 | `#0b0c0b` | 小黑身体、轮廓 |
| 原片奶油 | `#f3ead2` | 小黑眼白 |

界面 token 见 `assets/visuals.json`：`bg-base` 透明以露出背景，`bg-layer-1/2/3` 为 0.82–0.92 的深松玻璃，`border-l1…l4` 为 0.10–0.34 的苔玉描边，`brand-primary` 为 `#93e7b3`。

## 4. 角色四态

角色本体为官方原形坐姿（同一张裁切图），四态通过道具、色环和雾化区分：

| 状态 | 触发 | 叠加 | 说明 |
| --- | --- | --- | --- |
| `working` | 会话 `running === true` | 右下悬浮符文笏板、玉色火花、叶片 | 表示正在执行 |
| `waiting` | `pendingInteraction` 存在 | 右上琥珀问询符 | 表示等待回答/审批 |
| `idle` | `running === false` | 右上叶片“z”、苔绿光环 | 表示没有运行 |
| `unknown` | 状态缺失 | 下半身雾化、灰玉光环 | 表示状态未知 |

四张图共用 600×660 透明画布；显示时由 CSS 提供暖色 drop-shadow 和玉色径向光，避免黑猫在深绿背景里糊掉。`waiting` / `unknown` 在输入框被提问面板接管时，额外在会话标题旁显示 34px 圆形头像（琥珀描边）。悬浮版使用去瞳底图 + DOM 瞳孔：`working` / `waiting` / `idle` 可跟随鼠标，`unknown` 保持静态。

> 四态目前共用同一官方坐姿。若需要“抬爪/蜷睡/伏身”等不同官方姿势，可继续从影视帧中挑选镜头裁切；本轮优先保证角色形象与动画一致。

## 5. 界面样式

- 背景：`body[data-dsh-luoxiaohei-skin="xiaohei-forest"]` 铺影视帧背景 + 上下暗化渐变。
- 氛围层：`body::before` 是左侧/底部渐暗 + 220px 暗角，24s 极缓呼吸；不再叠加会遮挡原帧的紫藤/月轮光。
- 胶片层：`body::after` 是 180px turbulence 噪点 + 1px 苔玉内框，`mix-blend-mode: soft-light`。
- 角色动效：完整状态图有浮动/呼吸/等待倾斜；`prefers-reduced-motion` 下全部关闭。
- 悬浮布局：完整小黑绝对定位在输入栏右侧、状态行右端，不参与 `composerStack` 高度；输入卡片与轮数/步数/token/上下文状态一起贴底。
- 眼睛跟随：页面可见/前台时，瞳孔按指针相对脸部中心的方向偏移，最大约 3px；失焦或切后台回中。
- 主题卡：插件详情页显示背景缩略图、tagline、四态圆形缩略图；选中态用苔玉描边和淡绿渐变。
- 状态提示：状态切换时在右上角出现“森林耳语”短提示（等待/继续/收工/失联），3.6s 淡出；`idle` 只写“本轮结束”，不写成功。
- 按钮动效：hover 上浮 1px、active `scale(.985)`、focus 苔玉色环、160ms 过渡；所有动效遵守 `prefers-reduced-motion`。
- 范围：耳语只跟随当前打开的会话；没有声音/系统通知，也不接管 DSH 的审批、停止、发送逻辑。
- 等待态头像：34px 圆形裁切到脸部，琥珀描边，不占输入框位置。
